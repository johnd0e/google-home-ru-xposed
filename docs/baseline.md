# Device baseline

No Android device, emulator, or speaker has been runtime-validated for this project. Capture a baseline on a recoverable test instance before enabling the module.

Record only what is needed to reproduce the test:

- Emulator/device model, Android version/API, CPU ABI, and framework/sandbox version.
- Google Home package version and code, plus the speaker model and firmware.
- Whether Home launches, discovers the speaker, reaches language selection, and completes setup with the module disabled.
- The selected source and target language codes and the observed result.

Do not include account email addresses, passwords, access tokens, device identifiers, household membership, or full request bodies in notes or issue reports. Use a disposable/recoverable test instance; do not use a primary speaker setup as the first test.
